## Findings resolved in the rewrite

1. **Informative interruption.** A random count of completed searches does not establish a sample from the isolated endpoint distribution conditional on that count. A stopping example gives true expected quality 0.60, versus 0.55 from the draft's mixture. The revised note states the missing conditional-distribution requirement and models decisions from the current path state.
2. **Budget censoring and partial progress.** Fixed-budget endpoints and reached local optima are different random variables. A run can discover something useful without completing any local search. The revision retains initialized and queried candidates and records censored epochs.
3. **Agent versus island state.** The implemented island can hold several genotypes; an adoption by one recipient does not reset the island. Completion diagnostics in the current code classify the recipient's neighborhood, not a whole-island search opportunity. The new reference labels island-level aggregation as an empirical approximation.
4. **Marginals versus coupling.** Equal donor/recipient endpoint distributions do not imply duplicated futures. Independent continuations can improve the pair maximum without changing either marginal. The new A3 specifies shared future paths; a richer rival must specify a conditional continuation kernel and its dependence structure.
5. **Partial broadcast and mean quality.** The unreached agents average the mean island endpoint only after internal endpoint dissemination. The revised Control D includes that stage. Live propagation is evaluated jointly with quality, rather than multiplying separately averaged quantities.
6. **Bound equality case.** The Hartley–David extremal quantile is continuous; G=2 gives a uniform distribution. The incorrect “two-point-like” description is replaced by the equality condition and an exact attaining family.
7. **Temperature scope.** Zero-temperature copying is elitist. Positive-temperature copying can lose the best solution. A direct simulator witness found best observed fitness 0.9905458824 but final best 0.9437512271. Documentation now limits the monotonicity claim to the valid regime; historical dynamics and scores are unchanged.

## Answers to the four open points

- **Split A3:** yes. Duplicate continuation defines a joint process. Same or dominated endpoint marginals require a separate coupling and do not identify a unique maximum prediction.
- **What to count:** record all agent epochs, local-optimum events, adoptions, and censoring, but do not use their count as a substitute for the conditional path law. Preserve partial discoveries and post-adoption continuation.
- **Propagation:** begin with the known discrete contact kernel in search-disabled experiments. The note derives a separate Poisson/instant-takeover limit with rate `lambda_j = s*m*j*(G-j)/(G-1)` and mean all-island dissemination time `2*(G-1)*H_(G-1)/(N*m)`. Its assumptions must be checked before using it quantitatively.
- **Mean-agent prediction:** always report the observed metric. Make its prospective prediction confirmatory only after propagation and aggregation pass excluded validation; otherwise retain it as descriptive. A best-found result alone does not establish an explanation of the mean-performance window.

## What the executable reference contributes

R_copy samples isolated monotone island paths. Each island holds a path label and cursor. At each synchronous step it either copies a strictly better donor's pre-step state, or advances along its current path. Copying shares the donor's future path rather than opening another independent continuation. Contacts are explicitly supplied or generated by a declared kernel; fitness-dependent choices are part of the simulated history.

The reference handles no-contact search, abandoned partial paths, and terminal broadcast without forgetting earlier discoveries. At a fixed path library and horizon, it cannot discover a value above the best fully explored isolated path. That bound is proved for this reference and tested in the code. Whether actual agents obey its predictions is the substantive empirical test. Approximation of a multi-agent island by one representative is exposed as A2, not hidden in a free parameter.

The checks are not a design pilot. Full isolated-path calibration and event logs do not yet exist in the required form, and no primary model-error, power, or confidence-interval result has been collected for R_copy.
